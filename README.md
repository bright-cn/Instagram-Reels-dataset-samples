## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Instagram Reels 短视频的唯一 URL。 |
| `user_posted` | 发布该短视频的账户用户名。 |
| `description` | 短视频附带的文字描述。 |
| `hashtags` | 短视频中使用的主题标签列表。 |
| `num_comments` | 短视频的评论数。 |
| `date_posted` | 短视频的发布日期和时间。 |
| `likes` | 短视频获得的点赞数。 |
| `views` | 短视频的总观看次数。 |
| `video_play_count` | 视频的播放次数。 |
| `top_comments` | 短视频的热门评论列表。 |
| `post_id` | 短视频帖子的唯一标识符。 |
| `thumbnail` | 短视频缩略图的 URL。 |
| `shortcode` | 用于唯一标识短视频的短代码。 |
| `content_id` | 与短视频关联的内容 ID。 |
| `product_type` | 与短视频关联的产品类型（如有）。 |
| `coauthor_producers` | 短视频中标记的共同作者或制作人的用户名。 |
| `tagged_users` | 短视频中标记的用户列表。 |
| `length` | 短视频的时长（以秒为单位）。 |
| `video_url` | 用于访问短视频的 URL。 |
| `audio_url` | 短视频所用音频的 URL。 |
| `posts_count` | 发布该短视频的用户发布的帖子总数。 |
| `followers` | 发布该短视频的用户的粉丝数。 |
| `following` | 该用户关注的账户数。 |
| `user_profile_url` | 该用户 Instagram 个人主页的 URL。 |
| `is_paid_partnership` | 指示短视频是否属于付费合作内容。 |
| `is_verified` | 指示发布该短视频的用户是否为认证账户。 |
| `profile_image_link` | 发布该短视频的用户头像 URL。 |


## 使用场景

### 1. 社交媒体趋势分析
分析 Instagram Reels 上的热门主题标签和内容风格，以识别新兴趋势并为营销策略提供参考。

### 2. 网红营销洞察
通过分析点赞数、评论数和观看次数来评估网红的互动表现，从而优化合作和营销活动策略。

### 3. 竞争分析
通过研究发帖频率、互动指标和共同作者合作情况，了解竞争对手的内容策略。
